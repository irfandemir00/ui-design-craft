# UI Design Craft — Mandatory Activation Rule

Whenever a task involves designing, building, styling, refactoring, prototyping,
or reviewing **any** user interface—across **Web**, **Desktop Apps**, **Mobile
Apps**, **Video Game UI/HUDs**, or **inline Generative UI artifacts**:

1. **Read the `ui-design-craft` skill (`SKILL.md`) first** before writing UI
   markup, styles, or component code (and read relevant `references/` files).
2. **Complete the Pre-Code Design Brief** in your reasoning/plan (medium,
   user/player task, one aesthetic thesis, undertone-matched 60-30-10 color
   plan, display-vs-body font pairing with verified font imports, and
   layout/input grammar).
3. **Never ship AI slop**: no dark-slate + purple/indigo gradients, no raw
   `#000000` backgrounds, no `text-white` on bright yellow/amber/lime/cyan,
   no unloaded webfonts or ornate display fonts on body copy, no carditis
   (boxes inside boxes), no rainbow icon badges, no `✨`/`🚀`/`Sparkles`
   decoration, no buzzword copy (*"Supercharge"*, *"Seamless"*, *"Acme Corp"*,
   *"John Doe"*), no broken `tabular-nums`, and no medium mismatch (web landing
   pages inside desktop tools, shrunk tables on mobile, or SaaS cards in games).
4. **Verify before finishing**: ensure all 5 UI states, keyboard/touch/gamepad
   focus parity, and overflow/contrast checks pass; run `audit_ui_slop.mjs` on
   modified UI source files when working in a project workspace.
